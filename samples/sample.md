# MarkForge — пример документа

Это демонстрационный файл, показывающий возможности конвертера.
Здесь есть **жирный текст**, *курсив*, `моноширинный код`, ссылки и картинки.

## Списки

Маркированный список:

- Markdown → Word
- Markdown → EPUB
- Markdown → PDF
  - с вложенными пунктами
  - и кириллицей

Нумерованный список:

1. Перетащите файл в окно
2. Выберите формат
3. Нажмите «Конвертировать»

## Таблица

| Формат   | Чтение | Запись |
|----------|:------:|:------:|
| Markdown |   ✓    |   ✓    |
| Word     |   ✓    |   ✓    |
| EPUB     |   ✓    |   ✓    |
| HTML     |   ✓    |   ✓    |
| PDF      |   —    |   ✓    |

## Код

```python
from markforge import convert, Format

result = convert("book.md", Format.EPUB)
print(result.output_path)
```

## Цитата

> Хороший инструмент не мешает работать.
> Он просто делает своё дело.
